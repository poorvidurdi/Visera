Visera scores every price tick against your personal last-seen baseline — surfacing only the signals that actually matter. Set a price alert, walk away, and get a browser notification the moment it fires.

Idiosyncratic vs. Macro Decomposition
Distinguishes true asset-specific alpha from broad market noise: surfaces Idiosyncratic moves (stock-specific shocks) vs. Macro-driven moves (e.g. "AAPL -3%, but so was the S&P 500 — nothing stock-specific here").
Anomaly Scoring Engine
Every tick is scored across four signals — volatility-normalised move, volume anomaly, 52-week high/low crossing, and user alert crossing. Score ≥ 45 promotes a symbol to Significant.
Surgical Live Updates
WebSocket ticks arrive every 2 s and patch only the price cells that changed — no full re-renders, no flicker. HTTP polling runs every 5 s as a silent fallback with automatic reconnect.
Push Notifications
Crossing detection runs server-side on every tick. When your alert fires, an OS-level browser notification is pushed instantly — even when Visera is in the background or minimised.
Personal Baseline
% moves and scores are relative to when you last looked, not an arbitrary open price. Mark a row seen and that price becomes your new reference point.
Persistent Watchlist
Every watchlist change, alert price, and last-seen record is written to disk atomically on every mutation. Your data survives server restarts without a database.
Smart Ticker Search
Type a ticker symbol or company name to instantly filter the dropdown. Already-added symbols are excluded automatically so you can't create duplicates.
How to use Visera
1
Add a ticker — go to the Watchlist tab, type a symbol or company name in the search box and press + Add.
2
Set an alert price — enter a target price in the alert field on any row. You'll be notified the moment it crosses.
3
Allow notifications — accept the browser permission prompt so Visera can alert you even when backgrounded.
4
Mark seen — click ✓ seen on a row to set your baseline. All future moves are relative to that price.
5
Read the buckets — Significant and Notable need your attention; Quiet can wait.
